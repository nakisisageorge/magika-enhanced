🏗️ Component Details

Sync Flow

🐍 Sync API (Magika)

Drop-in replacement for upstream magika. Adds LRU caching (configurable size), custom rules integration, and full API compatibility. Used by CLI and sync Python code.

Async Flow

⚡ Async API (MagikaAsync)

Full async/await support with configurable concurrency (Semaphore). Uses thread pool executor for upstream blocking calls. Supports streaming, directory scanning, and async cache with asyncio.Lock.

MCP Flow

🤖 MCP Server

Implements Model Context Protocol. Exposes 5 tools: identify_file, identify_bytes, identify_paths, get_content_types, load_custom_rules. Transports: stdio (Claude Code) and HTTP/SSE (web agents).

Core

📋 Custom Rules Engine

YAML/JSON rule definitions with magic bytes (offset+pattern+mask), regex (pre-compiled), extension matching. Priority-based ordering (highest first). Hot-reload without restart. 47 built-in rules across 3 African domains.

Core

💾 LRU Cache

Content-addressable cache (SHA-256 of first 8KB + file size). Configurable size (default 1024). Sync version uses simple dict; async version uses asyncio.Lock for thread-safety. Hit rates typically 15-40% in batch workloads.

Core

📊 Benchmark Runner

Configurable iterations, warmup, concurrency levels, file sizes. Measures latency (avg/median/p95/p99), throughput, memory (psutil), CPU. Compares against python-magic, mimetypes, file(1). JSON output for CI regression detection.

Upstream

🦀 Upstream magika

Google's original: Rust core with tract ONNX runtime (~5ms inference), PyO3 bindings for zero-copy Python integration, 200+ content types, 3 prediction modes, overwrite rule system.

Rules

🌍 African Domain Rules

47 rules total: 12 Mobile Money (M-Pesa, Airtel, MTN MoMo, Orange, EcoCash, Wave, PesaLink), 10 Healthcare (HL7 v2/v3, FHIR, DICOM, CDA, X12), 16 Logistics (EDIFACT, GS1 EPCIS/CBV, Customs, eBL, eAWB).

🔄 Data Flows

🔵 Sync Identification

identify_path(path) → Check LRU cache → Cache hit: return cached result → Cache miss: upstream.identify_path() in thread pool → Apply custom rules → Cache result → Return MagikaResult

🟣 Async Identification

await identify_path(path) → Check async LRU cache (asyncio.Lock) → Cache hit: return → Cache miss: run_in_executor(upstream.identify_path) → Apply custom rules → Cache result → Return

🟢 Batch Async

await identify_paths(paths, max_concurrent=50) → Create Semaphore(50) → Spawn tasks with semaphore → asyncio.gather(*tasks) → Results in order → Progress callback support

🟠 MCP Tool Call

JSON-RPC request → Validate with Pydantic → Route to MagikaAsync method → Return formatted TextContent → JSON-RPC response. Schema validation on all inputs/outputs.

🟡 Custom Rule Match

match(content, path) → For each rule by priority: 1) Magic bytes (offset+pattern) 2) Regex (pre-compiled) 3) Extension (if path) → Return first match or None → Upstream handles non-matches

🔴 Benchmark Run

Generate fixtures → Warmup runs → Timed iterations (perf_counter) → Memory/CPU sampling (psutil) → Statistics (mean, median, stddev) → Compare tools → JSON output → Regression check
